# 口袋番茄钟 · 纯净版（POCKET POMO LITE）产品需求文档

| 项 | 内容 |
| --- | --- |
| 基线分支 | `demo/cat-themed-pomodoro-timer` |
| 文档状态 | 已与需求方逐项确认，进入实现 |
| 硬件平台 | FoloToy AI Passport（ESP32-C3） |
| 日期 | 2026-08-24 |

## 1. 背景与目标

官方示例应用"口袋猫咪番茄钟"以宠物养成为主钩子：完成番茄让猫成长、满级后循环羁绊。需求方不要养成系统，希望把这台设备变成一台插电即用的桌面专注工具，诉求归为六条：只保留番茄钟功能；计时界面显示剩余时间；闲时显示当地日期时间；一段时间无操作自动息屏；时长档位从 3 档扩充；提供每日/每周专注统计。

### 已有方案调研

实现前搜索了 GitHub 上的 ESP32 番茄钟项目，结论是没有可直接复用的实现：

| 项目 | 平台 | 与本需求的差距 |
| --- | --- | --- |
| ricroad/folotoy-pipboy-living-clock | 同为 AI Passport 硬件 | Pip-Boy 风格桌面时钟，非番茄钟；USB 校时而非 WiFi；无统计 |
| einoko/Tomato32（98 star） | Waveshare S3 触摸屏 | 触屏交互；无闲时时钟；无每日/每周统计 |
| MHYeung/Syncodoro | CYD 黄色板 | 功能面最接近（NTP + 历史记录），但走 SPIFFS CSV + Web 面板，硬件与框架均不同 |

"WiFi SNTP 校时 + 断电推算回退 + 分场景息屏 + NVS 逐日统计 + 三键 ADC 交互"的组合没有现成轮子。pipboy 项目验证了同硬件上"无操作自动息屏"的可行性，可作参考。

## 2. 硬件与资源边界

| 项 | 事实 | 对设计的影响 |
| --- | --- | --- |
| 主控 | ESP32-C3，无 PSRAM | UI 内存受限，LVGL 池维持 24KB |
| Flash | 4MB（保守配置，兼容 8MB 批次） | 加入 WiFi 协议栈后固件将超过默认 1.5MB factory 分区，需自定义分区表 |
| RTC | 无 | 真实时间唯一途径是 WiFi SNTP；断电后时间丢失，需推算回退 |
| WiFi | 芯片内置 2.4G，当前固件未启用 | 需新增 esp_wifi/netif/lwip 依赖与后台连接任务 |
| 显示 | ST7789 240x320，背光 LEDC PWM 可调 0-100% | 息屏 = 背光 0%（CPU 照常运行，按键为 ADC 轮询无中断） |
| 按键 | UP/DOWN/OK 三键共用 ADC，长按 OK 由主菜单全局拦截用作返回 | 应用层只处理单击/双击 |
| 电量计 | CW2017，只读 SOC 与电压；无充电检测引脚 | 固件无法感知充电状态，息屏是唯一省电手段 |
| 音频 | ES8311 方波提示音 | 提示音在独立任务合成，不阻塞 UI |

电力使用说明：设备插电长期使用时电池常处满电，锂电容量会逐年渐进衰减（固件无法干预）；本设计的分场景息屏同时兼容插电桌面与离电携带两种形态。参考同类 ESP32 设备，常亮屏整机电流约 40-80mA，实际续航取决于电池容量（仓库未提供），以实测为准。

## 4. 功能需求详述

### F1 计时核心

专注档位共 9 档，UP/DOWN 在闲时循环切换，默认 25 分钟：

| 档位 | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 | 9 |
| --- | --- | --- | --- | --- | --- | --- | --- | --- | --- |
| 分钟 | 5 | 10 | 15 | 20 | 25 | 30 | 45 | 60 | 90 |

休息时长按专注档位映射：25 分钟及以下休息 5 分钟；30-45 分钟休息 10 分钟；60-90 分钟休息 15 分钟。每完成第 4 个番茄（本轮序号为 4/4 的那次完成），当次休息时长翻倍（即 10/20/30 分钟）。

会话判定沿用原版规则：倒计时自然走完才算完成，才计入统计；暂停次数不限、不影响完成判定；暂停后经 UP 发起、二次确认后放弃的会话作废、不计数；放弃确认 5 秒无操作自动取消。断电重启后，未完成的专注/休息以暂停状态恢复；完成瞬间断电由 `reward_pending` 标志保证不重复发奖、不重复计数。原版的"本轮序号 n/4"状态栏保留，作为长休息进度的提示。

### F2 专注界面

```
+------------------------+
| WHIP 2/4         87% | |   <- 状态栏：本轮序号 + 电池图标/电量
|   +---------------+   |
|   |               |   |   <- 四角瞄准框（与闲时屏同款）
|   |    (heart)    |   |   <- 108px 大血心：专注放血从顶部排空，
|   |               |   |      休息回血从空补满；每秒心跳闪烁；
|   +---------------+   |      暂停=心脏停跳（暗红血量）
|        12:34           |   <- 48px 大号倒计时（血心下方）
| PAUSE                   |   <- 状态/操作提示
+------------------------+
```

以撒风（The Binding of Isaac）视觉：专注即被鞭打放血、血心排空；休息即回血、同一颗心从空补满，回到闲时屏血心行 +1；暂停即心脏停跳（暗红）。结算（3 秒）：满心闪烁 + 中央 `+1` 与 WHIP LANDED，配三连响提示音。原版刻度环与番茄装饰删除。

### F3 闲时时钟

```
+------------------------+
| MON 08-24        87% | |
|  [    14:23  *     ]  |   <- 自绘像素大时钟（49px 数字）+ 四角瞄准框
|                        |      （* 为未校准小圆点，冒号红色呼吸闪烁）
|    <3 <3 <3 <3         |   <- 今日已吃鞭数：一排小血心（最多 10）
|                        |
|  TODAY 3 WHIPS 75 MIN  |   <- 今日摘要
|      FOCUS 25 MIN      |   <- 当前选中档位（红色，3 倍像素字）
|       GO WORK!!        |   <- 街机 Boss 警告体：粗体右倾像素字 +
+------------------------+      硬阴影 + 每 2s 抽搐一次
```

闲时屏全屏像素渲染（自绘 5×7 像素字体）：日期、电量、摘要、档位均为像素字，与时钟、血心行统一质感。24 小时制，时区固定 UTC+8，日期格式 `MON 08-24`。时间未同步但有推算基准时，时钟旁显示小圆点标记；完全无时间基准时显示暗色 `--:--`。今日摘要、血心行与档位行来自统计模块与模型，每分钟刷新。

GO WORK!! 为 retro arcade boss warning 风格：仅打包 `G O W R K !` 所需的粗体像素字形（笔画 2px），右倾斜切、顶行橙红高光、深红硬阴影（偏移 3px）；静态细节含 WORK 的 O 基线下沉、第一个感叹号顶部削角、第二个感叹号行内 1px 错位。动画平时完全静止，每 2 秒发作 160ms：4 个离散步进（+2/0 → -2/+1 → +1/-1 → 复位，40ms 每帧），第 2/3 帧叠加 glitch——主字与阴影横向拉开并出现暗红 ghost，随即恢复。实现上咆哮窗口内 LVGL timer 临时切至 40ms，结束恢复 200ms；场景切走（开始计时/进统计页）立即终止并复位帧率。

### F4 时间同步

时间状态机为三态：

| 状态 | 含义 | 时钟显示 |
| --- | --- | --- |
| NONE | 从未同步过且无锚点 | `--:--`，统计完成只计累计 |
| ESTIMATE | 有上次持久化的锚点，按 锚点 + 开机时长 推算 | 正常走时 + 未校准圆点 |
| SYNCED | SNTP 已同步 | 正常走时，无标记 |

WiFi 凭据写在 `main/wifi_config.h` 两个宏（SSID/密码）。SSID 为空时进入纯离线模式，不初始化 WiFi。凭据有效时的连接策略：开机即后台连接（不阻塞界面），获得 IP 后启动 SNTP（服务器 ntp.aliyun.com 与 pool.ntp.org，同步间隔 60 秒）；首次同步成功后关闭 WiFi 省电；此后每小时开启一个约 60 秒的重连窗口完成重同步再关闭；持续连不上时每 30 分钟重试。开机 30 秒内未获得 IP 则放弃本次连接等待下个窗口。

推算回退的锚点持久化与模型状态共用同一 NVS blob：任何一次状态持久化都会把当时的墙钟估计写入锚点，因此运行中（含每分钟检查点）锚点新鲜度在 1 分钟内；闲时每小时额外刷新一次。断电重启后估计值 = 最后锚点 + 本次开机时长，误差为断电时长（接受，不做补偿）；恢复网络后自动回到 SYNCED。完成番茄时若处于 ESTIMATE，按推算日期记账（接受错记，不做追溯重分配）；若处于 NONE，只计累计总量。

### F5 背光与息屏

| 场景 | 阶段一 | 阶段二 | 阶段三 |
| --- | --- | --- | --- |
| 闲时 | 100% 保持 15 秒 | 10% 至累计 120 秒 | 熄灭 |
| 专注中 | 100% 保持 5 分钟 | 50% 长期 | - |
| 专注已暂停 | 100% 保持 60 秒 | 10% 长期 | - |
| 放弃确认 | 100%（本身 5 秒超时） | - | - |
| 结算动画 | 100%（本身 3 秒） | - | - |
| 休息提示 | 100% 保持 15 秒 | 10% 至累计 120 秒 | 熄灭 |
| 休息中 | 100% 保持 10 秒 | 10% 至累计 30 秒 | 熄灭 |
| 休息已暂停 | 100% 保持 60 秒 | 10% 长期 | - |
| 统计页 | 100%（10 秒无操作自动退出回闲时） | - | - |

计时基准：任一按键活动刷新"最后活动时间"；场景切换（如专注转休息）重置场景计时。熄灭状态下任意按键只负责唤醒（恢复 100% 并刷新活动时间），本次按键不触发任何动作，防止盲操作误启动。专注完成与休息完成两个事件强制亮屏 100% 并播放三连响，随后按新场景的阶梯重新计时。长按 OK 返回主菜单由 main.c 拦截，主菜单自行恢复背光，与本策略无冲突。

### F6 统计

指标定义：番茄数按完成个数计；专注分钟按该次完成档位的分钟数计（5 分钟档与 90 分钟档不等价，柱状图纵轴统一用分钟）。今日 = 当前本地日期；本周 = 周一起的 ISO 周；近 7 天 = 含今日往前的 7 个自然日；累计 = 设备生命周期总量（从 v1 旧数据继承原 completed 计数）。

数据模型：90 个逐日桶（日期 + 番茄数 + 分钟数）+ 两个累计总量，随模型状态存同一 NVS blob（总增量约 580 字节）。仅在番茄完成与小时级锚点刷新时写入，对 Flash 寿命无压力。日期用"本地时区 UTC+8 的 epoch 天数"表示（uint16 覆盖至 2170 年）。

统计页（闲时双击 UP 进入，OK 退出，10 秒无操作自动退出）：

```
+------------------------+
|      STATISTICS        |
|  TODAY 3 POMOS 75 MIN  |
|                        |
|  |     #              |   <- 近 7 天柱状图（纵轴分钟，
|  |  #  #     #         |      今日柱红色高亮）
|  |  #  #  #  #  #  # # |
|  M  T  W  T  F  S  S   |   <- 星期标签
|                        |
|  WEEK 12 POMOS 305 MIN |
|  ALL  345 POMOS 8200MIN|
+------------------------+
```

闲时主屏常驻"今日 X 番茄 Y 分钟"摘要，即统计的常驻入口。

### F7 保留的原版交互

双击 DOWN 静音切换（顶栏 M 标记）；暂停后 UP 发起放弃、UP 再按确认、DOWN/OK 取消；长按 OK 保存为暂停并退回主菜单（main.c 全局行为）；断电重启以暂停状态恢复；运行中每分钟写一次 NVS 检查点。

### F8 提示音

| 事件 | 音效 |
| --- | --- |
| 开始专注 | 880Hz 90ms + 1175Hz 110ms（沿用） |
| 暂停 | 660Hz 100ms（沿用） |
| 专注完成 | 三音符上行连响三遍 |
| 休息结束 | 三音符上行连响三遍 |

静音开关对所有提示音生效。

## 6. 数据持久化设计

存储结构升级为 v2（单 blob，magic + version + size + 载荷 + CRC32，沿用异步单槽写任务）：

| 字段组 | 内容 |
| --- | --- |
| 模型状态 | state、selected_index、reward_pending、pomodoro_round、pending_break_min、muted、remaining_sec、session_id、break_remaining_sec |
| 时间锚点 | anchor_unix（上次持久化时的墙钟估计，0=无） |
| 统计 | total_pomos、total_focus_min、90 个逐日桶（环形，head+count） |

v1 迁移规则：校验旧 magic/CRC 通过后，继承可映射字段；selected_index 按分钟值查新档位表（15->3、25->5、45->7，查不到回默认）；累计总量继承旧 completed_sessions/completed_focus_min；逐日桶清空（旧数据无日期信息）；锚点置 0。任何校验失败回默认值。写入时机：按键状态变化、每分钟检查点、完成事件、统计记录、小时级锚点刷新。

## 7. 错误处理与降级

| 场景 | 行为 |
| --- | --- |
| WiFi 凭据为空 | 纯离线模式，不初始化协议栈，时间走推算或 --:-- |
| WiFi 连接失败/超时 | 30 秒后静默放弃，界面不受影响，按周期重试 |
| SNTP 长期不可用 | 维持 ESTIMATE 推算走时，圆点提示 |
| NVS 初始化失败 | 计时功能照常，不持久化，顶栏不提示 |
| 存储数据 CRC/版本不符 | 回默认值（v1 走迁移） |
| 电量计缺失 | 顶栏 --%（沿用原版） |
| 音频初始化失败 | 无声运行（沿用原版） |
| 完成时无时间基准 | 只计累计总量，不落日期桶 |

## 8. 非目标

以下明确不在本期范围：宠物/养成类任何元素；Web 面板、USB 导出、CSV；多时区/夏令时（固定 UTC+8）；中文界面字体（遵循仓库英文 UI 约定，可作后续独立需求）；深睡（按键无中断唤醒能力，仅背光熄灭）；充电检测与电池保护。

## 9. 验收清单

主机测试（gcc 直接编译运行）：

- 模型：9 档循环切换、默认 25 档、休息映射（5/10/15）、第 4 番茄翻倍（10/20/30）、完成/暂停/放弃/恢复/断电恢复行为
- 日期：epoch 天数与年月日互转、星期计算、UTC+8 边界（UTC 23:30 属次日）、周一起始
- 统计：当日累加、跨日新桶、90 天环形淘汰、周聚合、近 7 天查询、无日期桶只计累计

上机验收（需真机）：

- 填入凭据后 30 秒内时钟从 --:-- 变为真实时间，圆点消失
- 拔电重启：时钟回到推算时间并带圆点，连网后自动恢复
- 闲时 15 秒降亮、120 秒熄灭；熄灭后首键仅唤醒
- 专注 5 分钟后半亮；专注完成自动亮屏 + 三连响
- 休息 10 秒降亮、30 秒熄灭；休息结束自动亮屏 + 三连响
- 完成一个番茄后闲时摘要与统计页数字一致；断电重启后统计保留
